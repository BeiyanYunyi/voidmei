# Kotlin 版试用

当前为 Kotlin Multiplatform / Compose Desktop 迁移开发版，尚未完整替代 Java 版。Linux 已有模拟遥测和包运行验证，真实游戏及 Windows/macOS 验收仍未完成。详细范围与验证记录见 [迁移说明](kotlin-migration.md)。 用户已在 NixOS 实际游戏中人工确认水平仪姿态方向正确、兼容模式透明 HUD 正常；这项透明 HUD 结论不覆盖原生模式。

## 启动与恢复

NixOS 在源码目录启动独立包：

```bash
nix run path:. -- --no-hud
```

首次构建会下载依赖。默认入口现为独立 Kotlin 包，启动不需要 Gradle；原 `#kotlin-offline` 命令继续有效。旧 Java 版可显式使用 `nix run path:.#legacy-java`。默认 `nix develop path:.` 提供 Kotlin/JDK 21 环境，旧 Java 8 开发环境使用 `#legacy-java`。

从源码运行需要 JDK 21；NixOS 可先进入 `nix develop path:.#kotlin`：

```bash
./gradlew :desktop:run --args=--no-hud
```

`--no-hud` 先显示主窗口，便于调整配置；即使保存了“下次启动进入托盘”，也能使用这个入口恢复。主窗口的“渲染信息”显示当前渲染后端。开启 HUD 后若出现卡顿，可重新以 `--no-hud` 启动，在主窗口启用“HUD 兼容显示”再打开 HUD。

主窗口展开“渲染信息”后，可勾选“软件渲染（重启后生效）”。该偏好请求 SOFTWARE_FAST，关闭后恢复平台默认后端；实际后端以重启后的渲染信息为准。显式 `SKIKO_RENDER_API` 环境变量或 `skiko.renderApi` JVM 参数优先于保存的偏好。软件渲染与“HUD 兼容显示”独立，已有兼容 HUD 设置不会因切换渲染偏好而改变。

## Linux 数据与旧版并存

Kotlin 配置默认存于 `${XDG_CONFIG_HOME:-$HOME/.config}/voidmei/settings-kmp.json`，可用 `VOIDMEI_CONFIG_HOME` 指定配置目录。它不会直接使用或覆盖旧版 `ui_layout.cfg`；需要在设置中预览并导入旧配置。

新配置的 FM、录制及自定义语音目录默认位于 `${XDG_DATA_HOME:-$HOME/.local/share}/voidmei` 下的 `data/`、`records/`、`voice/`。`VOIDMEI_HOME` 只改变新配置的这些默认数据路径，不改变 Kotlin 配置文件位置，也不覆盖已保存的路径。已有配置请在界面中修改路径。FM 数据需自行提供，安装包不包含游戏 FM 数据。

## 连接与查看读数

主窗口“遥测服务器”默认是 `http://127.0.0.1:8111`。修改地址后点击“连接”。等待飞行和连接中断会分别显示状态；缺失读数显示“—”，不要当作零值。

刷新间隔可使用预设，也可输入 10–5000 的整数毫秒后点击“应用刷新间隔”，例如旧版常用的 80 ms。大于两秒的采样间隔无法形成部分连续采样估算，通常使用较短间隔。

导入旧版配置的 `httpPort` 会更新已保存地址的端口并保留主机地址；预览应用后点击“连接”切换当前连接。

旧版合法的 10–19 ms 刷新间隔也可原值导入。实际采样周期还包含请求与处理耗时，设置 10 ms 不保证取得 100 Hz 的新遥测数据。

SEP 的动能项和加速度使用最近一秒的速度趋势，减轻接口速度重复、量化造成的跳变；爬升率仍使用当前值。趋势平滑会带来短暂延迟，刚连接时历史不足，读数可能尚未稳定。断线、换机或速度缺失会清空趋势；刷新间隔超过一秒时使用最近两个样本。

WEP 燃料与续航显示的是模型和已观察消耗推算的上限。短暂遥测延迟时隐藏估计，恢复后保留此前已观察到的消耗；未知时间段不按旧油门补算，所以仍可能高估实际剩余量。真正断线、换机、模型变更或输入无效会重新开始估计。

全机动力百分比在没有可用 FM 参考时，可使用连续五秒全油门采样确认的历史峰值。短暂延迟保留已经确认的参考，恢复后按新功率／推力计算百分比；尚未完成的五秒采样重新开始。真正断线、换机、发动机编号或动力类型变化、必要输入缺失及时间回退会清除历史参考。该峰值仅反映已观察数据，不代表理论性能上限。

热耐受显示模型预算的区间，不是发动机实际剩余寿命。短暂延迟期间隐藏旧值；两份有效样本间隔不超过 2.5 秒时，恢复后的区间同时考虑未知期间可能过热或冷却。间隔更长、真正断线、换机或模型变化会重新估计，缺少恢复参数时不会凭空恢复预算。

开启语音后，可在“逐条语音设置”中打开默认关闭的“连接成功提示音”。它在首次收到有效飞行数据或换机时尝试播放 `start1.wav`，沿用全局音量和语音包，也可单独选择包。存在告警时跳过；十秒内重连不重复播放，飞行中开启不补播。

逐条语音旁的“试听”使用已应用的包和当前音量，不改变自动播报开关。音量为零时无法试听；可点击“停止试听”或收起设置停止。实际告警优先，不会被试听打断。

没有游戏时，可在另一个终端启动仓库中的合成遥测服务：

```bash
python3 script/mock_8111.py serve --port 8112 --file script/mock_data.json
```

然后在新版中连接 `http://127.0.0.1:8112`。这是模拟数据，用于检查界面与录制，不代表真实游戏验证。

## 查看渲染诊断

主窗口的“渲染信息”显示实际绘制后端、请求后端、显示路径与当前窗口缩放。两种后端不同时会标注；主窗口和 HUD 可能使用不同后端。设备详情仅在显示路径提供时显示，OpenGL 名称本身不能证明硬件加速。诊断变化也会写入启动日志，反馈闪烁时可附上主窗口与 HUD 的对应记录。

## 调整 HUD

在主窗口打开“HUD 字段设置”，选择读数、调整顺序、字号和宽度。隐藏标签只隐藏名称，保留数值。“HUD 读数列数”可选自动、单列或双列，飞行和发动机表格均使用此选择。固定列数按从左到右、从上到下排列，较长标签与读数在单元格内换行；主窗口表格不受影响。自动模式下紧凑表格会记住当前布局中较宽的读数，避免位数变化让字段在一列和两列之间跳动；加宽窗口或调整字段、字号、高度来源会重新适配。

点击“预览 HUD 布局”可在进入游戏前查看示例读数，并在设置窗口继续调整字段、字号、列数、颜色和宽度。预览使用明确标注的示例数据，不开启真实 HUD，不写入飞行记录；模型相关读数可能显示未知。棋盘背景用于观察透明度，关闭预览不会关闭应用。

预览窗口可切换“正常读数／告警示例／缺失数据”，检查告警配色、多条提示和未知读数的布局。示例模型仅用于展示，不代表当前飞机的限值，也不会播放告警语音。

预览会为当前选中的发动机编号补充示例读数与模型，3 号及以上发动机也可检查耐热时等字段的布局；这些示例不代表当前飞机实际拥有相应发动机。“缺失数据”模式仍显示未知读数。

预览被遮住或最小化后，再点击“预览 HUD 布局”会恢复并前置原窗口，保留当前示例模式和窗口尺寸。

点击 HUD 字段设置的“恢复默认”后，可用“恢复重置前布局”取回本次设置界面中最近一次重置前的布局。它只恢复该按钮重置的布局项，不回退连接地址、记录设置、HUD 开关或窗口位置；关闭应用后不保留这份临时回退记录。

HUD 内容超过窗口高度时，右侧细条显示滚动位置和可见比例；内容能完全显示时自动隐藏。纵向模式可先在主窗口关闭鼠标穿透，再使用滚轮。单窗口分区模式始终穿透；应在设置中增大区域、缩小字号或减少字段，让需要的内容完整显示。

分区布局预览会在发生纵向滚动溢出的区域右下角标注“内容超出区域”，调整到能完整显示后自动消失。提示仅出现在预览中，不进入运行中的 HUD；它不检测文字横向截断、区域互相遮挡或地图／姿态等图形内容的裁剪，仍需结合正常、告警和缺失数据样例检查布局。

告警列表有独立的“告警超出区域”提示。可用“全部告警样例”检查最拥挤的情况，再调整区域高度、字号或告警类别；关闭样例后仍按实际触发的告警显示。

游戏消息区域可设置“单条消息最大行数”：默认完整显示，也可选 1、2、3、5 或 10 行，超出部分显示省略号，避免一条长消息占满区域。此设置按区域保存并随预设导入导出，完整原文仍保留在“查看游戏消息”的历史列表中。

添加字段区域可按中文名称、字段 ID 或单位搜索，忽略英文大小写；空格分隔的多个关键词需同时匹配，例如“推力 kgf”。搜索不隐藏已选读数，也不改变其顺序；清除搜索恢复全部可添加字段。

可搜索“燃油减少率估计”（`fuel_loss_rate`）添加 kg/min 读数。它使用最近最多 30 秒燃油变化，至少需要 10 秒连续样本，包含泄漏和抛弃油箱；补油或数据中断后重新采样。未知显示“—”，只有完成采样且燃油未减少时才显示零。

HUD 字段设置中启用“发动机读数”后，可逐项选择油门、转速、功率、温度及控制面板读数。取消不需要的字段可缩短面板；用“上移/下移”直接调整显示顺序，重新加入的字段排在末尾。发动机编号缺失时不会替换成其他发动机，全部取消时显示“未选择发动机读数”。

动力／控制旧设置的目标选择会同时显示分区名称、ID 与发动机编号。超过六个候选时可按名称、ID 或 `#编号` 搜索，多个关键词同时匹配；默认每次显示六个候选，可点击“再显示”继续展开。当前选择始终保留，搜索无结果也不会取消目标；清除搜索后恢复首批候选。其他旧窗口已占用的目标保持禁选，像素坐标缺少屏幕尺寸时仍不能选择目标。

导入含动力或控制窗口信息的旧配置时，可在预览中勾选“新建动力信息分区／新建引擎控制分区”。新区域使用 Kotlin 默认尺寸和外观，分别应用动力／控制字段预设；控制区域默认采用无表格的混合仪表布局，两者均明确使用 1 号发动机；可在 HUD 分区设置中修改编号。新建后在下方明确选择位置、显示开关、列数的迁移目标。取消新建会停用指向该区域的迁移；新旧分区合计不得超过 32 个。已有对应分区时可直接选择它，无需再新建；开始新的导入预览后再次勾选新建，会生成另一个区域。

引擎控制字号可选迁移：支持该面板 `:font-size` 和历史 `fontSize` 项（-6–20 整数），属性优先。基准值为 `24 + 偏移`；条长为基准值的四倍，厚度为整数除二，标签／数字／单位文字为半字号取整并使用粗体。选择目标发动机分区后一起应用图形尺寸、文字大小、字重和 100% 文字缩放；字体名称、分区位置与大小、布局方向保持不变。支持本次新建的控制区域，且不能与动力字号选择同一目标。按逻辑 dp／sp 换算并应用当前系统缩放，旧窗口间距和逐像素 DPI 取整没有复刻。

动力信息表格字号可选迁移：支持 `:font-size` 属性和动力面板内 `fontSize` 项（-6–18 整数），属性优先。预览会列出标签、数字、单位字号，明确选择一个发动机分区后才应用。数字按 `24 + 偏移`，标签／单位按其一半取整；标签和数字为粗体、单位常规，并将目标区域字体缩放设为 100% 以免重复缩放。字体名称和区域尺寸保持原值；引擎控制字号使用上方独立的图形尺寸换算规则。

发动机分区可单独关闭“显示读数表格”，保留控制条、增压器图形、标题及相关说明；横向控制条会补充当前数值，横排油门也会显示数值说明。仪表文字沿用字段精度，FM 动力量保留一位小数；条形满刻度不会截断油门、混合比的实际显示数值。所选字段仍决定仪表内容；仅有数字而没有图形的字段需要开启表格。隐藏表格不会隐藏有效告警：告警改为对应字段的文字提示，全部所选读数缺失时显示明确提示。已有布局默认保持表格显示，其他分区不受影响。旧配置导入中新建的控制区域默认隐藏表格并选择混合布局，新动力区域保留表格；均可在分区设置中调整。

发动机分区的“控制条尺寸”可设置条长（48–512 dp）和厚度（8–48 dp），两项均有效后一起应用。此分区的油门、连续控制条和增压器刻度共用尺寸；横条长度不超过可用宽度，竖条长度对应高度，文字和窗口尺寸独立。点击“恢复默认自适应尺寸”即可还原原有横条填满宽度和竖条默认大小。调整后请检查区域预览，过长的竖条可能需要增大区域高度。

发动机分区的“连续控制条布局”提供横排、竖排、混合布局三种互斥选项。混合布局将油门、转速控制和动力量竖排，混合比与水／油散热器横排；增压器始终保留水平刻度。发动机分区可独立开启“显示整机燃油余量”，显示整架飞机的百分比及水平燃油条，不按发动机拆分。关闭图形后保留数值和告警；所选发动机缺失时整机燃油仍可显示，燃油数据缺失时显示原因。已有配置默认关闭此选项。导入旧配置的 `disableEngineInfoLFuel` 时，可在预览中选择现有或本次新建的发动机分区接收显示／隐藏设置；默认不选择分区，原有全局飞行燃油字段迁移仍会应用。旧配置默认横排，上一版保存的竖排布尔值自动恢复为竖排。关闭附带图形保留方向选择，各分区独立保存。量程沿用油门 110%、混合比 120%、其他 100%，缺失数据不画控制条；布局方向与旧控制字号尺寸换算均可分别选择，旧窗口间距仍未复刻。

发动机分区的标签字体、标签字号和字重同时用于表格标签、发动机标题、控制条说明、增压器刻度说明和换档建议。未设置独立样式时保留各元素默认外观；清除设置恢复继承。数字字体与字重独立，控制条长度和刻度数据不因标签样式变化而改变。

动力与控制窗口的标签字体也可独立迁移：优先读取面板 `:font`，动力面板缺少该属性时兼容其 `fontName` 设置项。预览中明确选择目标发动机分区后，仅改变读数标签字体，保留数字字体、字号、全局字体和其他分区。默认不迁移，可取消选择；缺少系统字体时回退到默认字体。只有字体的旧文件也可预览，并可在本次导入中新建相应区域。

旧版“动力信息／引擎控制”的显示开关可分别迁移至两个已有发动机分区。兼容独立开关项及 `:switch-key`／`:visible` 面板属性，沿用现有显式开关优先规则。预览默认不迁移，选择目标后显示“原可见状态 → 导入状态”；两个旧窗口不能选择同一目标，先取消原选择即可重新分配。只改变区域显示开关，保留全局 HUD、发动机编号、字段与位置；也可应用到本次明确选择新建的分区。

“动力信息／引擎控制”的旧位置也可分别迁移到两个明确选择的发动机分区，默认不迁移。位置与显示开关分别选择目标，请在预览中核对分区名称；尺寸、字段及其他外观设置保持原值。每轴大于 2 的坐标按旧屏幕像素换算，其余按比例换算；像素坐标需先填写旧屏幕宽高，缺少尺寸时仍可迁移另一个使用比例坐标的窗口。预览显示原坐标和应用坐标，靠近边缘时按现有分区尺寸移回画布内。

旧设置导入现支持“动力信息”面板的 `hudColumns`（1–8 列）。预览中明确选择一个已有发动机分区后才应用，默认不迁移；可查看“继承全局／原列数 → 新列数”，或选择“不迁移列数”取消。只修改目标区域的列数，其他区域、全局列数、字段、位置和发动机编号保持原值。尚无发动机分区时，可在本次预览中新建动力信息分区。

发动机字段增加“应用动力读数”“应用引擎控制”“应用默认字段”预设，会替换当前字段及顺序，应用后仍可逐项增删和排序。在分区设置中应用预设会自动启用该区域独立字段；可以给同一发动机创建两个区域，分别显示动力与控制。区域位置、编号、字体及图形开关保持当前设置。关闭“此区域独立选择字段”即可恢复全局继承。燃油、总重等整机数据在飞行字段中选择；这些预设不是 Java 两个旧窗口的自动导入。

旧版“耐热时”对应发动机字段中的“耐热时估计”（`heat_budget`），默认未选中。在 HUD 的发动机字段或发动机分区的独立字段编辑中搜索“耐热时”并添加，即可显示该编号发动机的模型工作预算区间。飞行字段中也可添加“1 号耐热时估计”（`heat_tolerance`）。多发动机可分别配置。区间包含未知初始损耗，不是实际剩余寿命；缺少匹配模型、温度或有效计时预算时显示“— s”。

耐热时和 WEP 燃料／可用时间的估算说明仅在设置页的“HUD 字段设置”中展示，HUD 保留数值与缺失值占位，节省显示空间。低温时显示“—”不代表零秒或无限寿命；进入有效计时档位后才显示相应时间区间。

发动机 HUD 的标题、缺失数据提示、推进功率说明使用配置的标签颜色与文字阴影，便于在透明背景下辨认。

“动力量（FM峰值）”（`fm_power_percent`）按所选发动机的模型功率或推力峰值显示 0–100% 读数，并注明参考类型。它需要匹配机型和发动机编号的 FM 峰值，不使用整机历史峰值代替；缺少模型时显示未知。

- “HUD 读数颜色”分别调整标签、普通数值、单位、告警数值和文字阴影。输入 `#RRGGBB` 或 `#RRGGBBAA`，最后两位是透明度；例如 `#00000080` 为半透明黑色。无效输入不会替换上次有效颜色。HUD 颜色留空时继承“表格默认配色”；默认配色中的阴影留空表示关闭。
- “高度读数来源”可选海拔、低空优先雷达、始终优先雷达；低空模式在有效雷达估计高度 ≤500 m 时切换。雷达值或单位推断不可用时回到海拔。默认显示海拔，只影响 HUD 的“高度”字段。
- “雷达高度估计”根据高度表单位推断换算为米，假定雷达仪表与高度表使用同一单位；需要连续有高度变化的数据，尚未判定时显示未知。可同时选择“雷达高度原值”核对，CSV 继续保存原值。
- “滑油压力原值”保留座舱 `oil_pressure` 读数，以“仪表单位”显示。单位与发动机归属未确定，不换算压力、不套用燃油低压告警。缺失或非法值显示未知，零值正常显示；CSV 的 `oil_pressure_raw` 列可用于历史分析与回放。
- 姿态仪采用蓝色天空、棕色地面；显示俯仰以抬头为正，机头抬起时飞机指针对应蓝色区域。
- “姿态图迎角极限线”控制模型极限虚线。关闭它不关闭迎角读数、余量条或告警。
- 准星可选择线框或本地图片、中心或右侧位置、尺寸；图片支持保持比例或方形拉伸。位置相对于 HUD 窗口，需要拖动 HUD 对准所需屏幕位置。图片使用外部文件路径，移动或删除文件后需要重新选择。
- 开启“HUD 鼠标穿透”后，点击会交给下方窗口；要拖动或关闭 HUD，请先回主窗口关闭穿透。该功能提供 Linux、Windows 和 macOS 实现；Windows/macOS 尚待实机验证。macOS 通过 OpenJDK 21 的 AWT 窗口桥接访问 AppKit，Gradle 启动和打包器会加入所需模块导出参数；使用其他 JDK 或自行拼装启动命令时，桥接不兼容会显示错误。

“切出游戏时隐藏 HUD”提供 Windows、Linux X11 和 macOS 实现。X11 根据窗口的本机 PID 和可执行文件识别游戏；窗口信息缺失、远程客户端或 Wine 加载器无法识别时保持 HUD 可见。macOS 读取 AppKit 前台应用的 PID 和可执行路径，仅以文件名 `aces` 识别原生游戏；两次查询之间发生切换、路径缺失或原生调用失败时保持 HUD 可见。Wayland 暂不支持前台检测，开关不可新启用，已保存的启用状态仍可关闭。Linux 原生游戏与 macOS 的实际切换效果待真机验证。

主窗口的“表格默认配色”作用于主窗口和 HUD 飞行、发动机表格，HUD 单独设色优先。其他图形和普通界面文字并不全部跟随。

## 单窗口分区布局

可继续使用 `nix run path:.#kotlin-offline` 和“HUD 兼容显示”。在 HUD 设置中点击“使用单窗口分区布局（试验性）”，所有运行中的 HUD 区域会绘制在同一个鼠标穿透窗口里。设置窗口和编辑预览仍独立存在。

1. 展开“调整分区位置与透明度”。“分区窗口覆盖范围”可选按画布尺寸或指定显示器；覆盖显示器时等比适配画布，宽高比不同时留出透明空白。
2. 用“+ 飞行读数”“+ 发动机”等按钮添加区域，同类可以重复添加。当前支持飞行、发动机、姿态、机械化、告警、游戏消息、地图对象、准星、罗盘和操纵面，最多 32 个区域。
3. 在飞行或发动机区域开启“此区域独立选择字段”，分别安排速度、高度、温度等读数；未开启时继承全局字段。发动机区域独立选择编号，缺少该编号的数据时显示未知，不改用其他发动机。
4. 打开“预览 HUD 布局”，启用“拖动区域”。拖动区域可移动，拖动右下角方块可改变大小；重叠时在“拖动目标”中指定被遮挡的区域。也可使用分区设置中的位置与尺寸输入。预览编辑会自动保存。
5. 分别设置“背景不透明度”和“内容不透明度”。例如，背景 0%、内容 100% 表示只有清晰文字和图形；背景 50%、内容 100% 表示半透明底板。区域外空白完全透明，所有区域仍统一鼠标穿透。

区域列表从底层到顶层排列，可用“上移一层／下移一层”调整遮挡关系。每区可单独设置字号、读数列数、标题和显示状态。“返回纵向 HUD 布局”保留分区配置，下次开启可以继续使用。

飞行和发动机区域可开启“此区域独立选择标签”，逐项隐藏读数名称，保留数值和单位。标签设置与字段选择相互独立：可继承全局字段但自定义标签。关闭独立标签后，飞行区域恢复跟随全局标签设置，发动机区域恢复显示全部标签；区域标签设置随布局预设保存。

飞行与发动机区域均可关闭“显示读数附带图形”，保留数字以节省空间。发动机图形随已选字段出现：油门满刻度 110%，转速控制 100%，混合比 120%，水／油散热器 100%；图形封顶时数字仍保留原值。未知值不会画成零。选择增压器字段后，匹配模型可显示换档建议，文字标明燃油方案和 15°C 模型估算；这不执行自动换档。

发动机区域可选择“推进功率”（kW），按该发动机推力与当前真空速计算。各发动机独立显示，一侧推力缺失只影响该侧；TAS 缺失时各侧均显示未知。

“推进效率估计”使用该发动机推进功率除以轴功率，沿用全机估计的 735 W/hp 换算参考。需要有效推力、TAS 和正轴功率；估计结果不截断到 100%。“效率”字段继续显示 API 提供的原值。

选中的推进功率或推进效率无法计算时，读数保留“—”，并在下方说明缺少有效 TAS、本发动机推力或正轴功率。数据恢复后提示自动消失；有效的零推进功率／零效率仍显示为零。未选择这些字段时不显示相关提示。

增压器档位图用圆点表示当前档位，有换档建议时用另一颜色的长线标出建议档位。缺少建议计算所需的数据时移除长线，有效的当前档位仍保留；关闭区域图形后，换档建议文字仍可显示。

操纵面区域可开启“显示二维操纵面图”，并同时选择副翼与升降舵。十字位置按遥测百分比绘制：副翼正值向右、升降舵正值向下，任一轴数据缺失时不显示位置标记。原单轴条形图保留；若内容放不下，可在预览中增大该区域高度。

区域较宽时，二维图与单轴读数自动左右排列，默认 440×260 dp 区域可容纳；窄区域改为上下排列，可按需增加高度。

操纵面区域还可单独选择“后掠”，将其百分比与舵面放在一起显示。后掠使用 0–100% 刻度，三种舵面使用 −100% 至 +100%；缺失后掠数据显示未知，不当作零后掠。

在“管理布局预设”中输入“布局名称”，点击“保存当前分区布局”，可保存最多 16 套。已有同名布局时按钮显示“替换同名布局”；可载入、重命名或删除。预设保存画布和区域配置，继承的全局字段、字体、颜色仍跟随当前全局设置。载入和删除各可撤销最近一次操作，恢复记录仅保留在本次页面中，不跨重启。

每套预设的“预览”按钮可打开只读样例窗口，先查看效果再决定是否“载入”。预览不改变当前 HUD 布局或预设，不提供拖动编辑；继承的字段、字体和颜色使用当前全局设置。

用“导出全部预设”将已保存的布局备份为独立 JSON 文件，选择一个尚不存在的文件名。在另一套配置中点击“读取预设文件”，核对列表后点击“添加 N 套预设”。同名项会跳过，添加后总数不得超过 16 套；导入不会直接切换当前 HUD。文件只保存画布与区域配置，不包含全局样式、字体或外部图片资源，大小上限为 1 MiB。

需要同时保留本机和文件中的同名布局时，点击该项的“修改导入名称”并输入新名称。名称首尾空格会去除，不能为空或超过 80 个字符；同一文件中的待导入名称必须各不相同。改名只影响添加的预设，原备份文件保持不变。

导入清单默认勾选全部布局，可取消不需要的项目；数量限制和名称检查只针对勾选项。未勾选项的改名草稿会保留，重新勾选后继续校验。接近 16 套上限时可只导入部分布局。

清单顶部提供“全选／全不选”，并显示选择数量和预计添加数量。只需要少量布局时，可以先全不选再逐项勾选；清单较长时向下滚动到“添加 N 套预设”完成导入。

预览中的“缺失数据”可检查未知读数；有消息或告警区域时，可用“密集消息”“全部告警样例”检查内容是否放得下。预览是合成样例，不代表实际飞机状态。

Linux 当前实现和隔离验证使用 X11；原生 Wayland 鼠标穿透尚未实现。新的分区布局仍需真实游戏验证，物理多屏混合 DPI 也尚未完成验收。实现与测试记录见 [单窗口 HUD](single-window-hud.md)。

## 恢复默认设置

主窗口的“恢复默认设置”会先显示确认预览，包括默认服务器、刷新间隔、HUD 模式和资源目录。确认后恢复全部已支持的设置并自动保存，同时重置窗口位置；Linux 恢复为兼容 HUD。已有模型、语音包和 CSV 文件保留。当前遥测连接继续使用原地址，点击“连接”后才切换至默认服务器。

“备份 KMP 设置”导出当前版本支持的全部设置，包括 HUD 分区及预设、全局字段、字体、颜色、窗口位置、服务器、热键、语音和资源路径。选择未存在的 JSON 文件名；不会覆盖已有文件。备份不包含模型、语音或飞行记录文件，也不承诺保留其他版本的未知 JSON 属性。

“从 KMP 备份恢复”读取后先展示摘要，点击“确认恢复备份”才替换当前设置并自动保存。录制中或配置无法保存时不能恢复。恢复的 HUD、语音和自动录制等开关会按配置生效；当前遥测连接仍保持原地址，点击“连接”后切换。软件渲染及启动选项需重启生效。跨机器恢复时检查资源路径和显示器配置；布局预设文件仍使用预设管理中的导入入口。

请先停止录制再恢复设置。配置读取或保存异常、正在退出或执行录制操作时，恢复入口不可用；取消预览不修改设置。

## 导入旧设置

打开“导入旧版设置”，选择 `ui_layout.user.cfg`，点击“预览旧设置”。检查预览和“未迁移”项目，再点击“应用预览设置”。预览本身不改设置，导入也不改写原文件。

有单条告警语音选择时，同时查找旧程序资源目录下的 `voice/`（未指定资源目录则使用配置所在目录）。存在时在预览中显示该路径，确认后将其作为语音目录；文件保持外部引用，不复制，请保留旧目录。单条包名和启用状态分别保留，导入不会打开原本关闭的告警。目录缺失时保留当前目录并提示，单个文件缺失时提示默认语音回退；确认后可在语音设置中试听。

旧引擎控制的油门、桨距、混合比、散热器、增压器开关可迁移到全局发动机读数字段。“桨距”在旧引擎控制中实际是转速控制百分比，因此不会改动新版桨叶角字段。动力量与燃油比例映射为全机读数；同一全机字段在其他旧面板中仍开启时继续显示。导入保留当前发动机编号、面板开关和分区独立字段；尚未开启发动机读数时，请在 HUD 设置中选择编号。

软件渲染优先读取旧程序资源目录中的 `gpu_compat.properties`（留空则用布局文件所在目录），因为旧版启动器实际读取的是该文件。文件不存在时使用布局中的 `gpuCompatibilityMode`；两者均未提供时保留当前选择。独立文件损坏、值无效或过大时提示并保留当前软件渲染设置，其他有效设置仍可导入。预览显示来源；确认后自动保存，重启生效，HUD 兼容显示选项不随之改变。

预览读取耗时较长时可点击“取消读取”，随后修改路径并重试。已取消读取的结果不会覆盖新预览；只有点击“应用预览设置”才会修改当前设置。

旧图片准星默认从配置文件所在目录的 `image/gunsight/` 查找。若配置和旧程序资源分开放置，填写“旧程序资源目录”，再重新预览。成功导入的旧图片采用方形拉伸和 HUD 右侧定位。

旧五类配色可迁移到表格默认配色及 HUD 专用颜色；其他文字、图形填充等未覆盖部分仍会报告。旧 `MonoNumFont` 可迁移到 HUD 表格数字字体；缺省或留空时继承旧 `GlobalNumFont`。需要在当前系统安装该字体；HUD 字段设置中也可填写专用字体名称，留空继承全局数字字体。未安装的字体会回退为默认等宽字体，设置页提示缺失并保留原名称。旧 `GlobalTextFont` 可迁移到全局文字字体，应用于主窗口、HUD 和离线模型窗口的主题文字；系统标题栏字体不受影响。设置中留空恢复默认，缺失字体会提示并回退。旧 `GlobalNumFont` 也迁移到独立的全局数字字体，用于主窗口飞行和发动机表格的读数；设置中留空使用默认等宽字体，缺失字体会提示并保留名称。显式 HUD 数字字体优先。旧像素坐标：坐标轴值大于 2 时，沿用 Java 规则按像素处理；其余值按比例处理。遇到像素坐标时，在导入预览中填写旧程序识别的主屏幕宽度、高度（系统缩放下可能不同于物理分辨率），换算到当前画布后再勾选位置迁移。宽高缺失或无效时不迁移位置、不补建分区，其他设置仍可应用。只含比例坐标的文件无需填写尺寸。

旧位置可选迁移：先创建单窗口 HUD 布局，再预览旧配置并勾选“迁移已有分区位置”。缺少对应类型时，可勾选“补建缺少的对应分区”，同时启用位置迁移；预览会列出新增分区的位置、尺寸和背景透明度。新增分区使用 Kotlin 默认尺寸、可见状态和透明度并继承全局字段，不还原旧窗口样式；超过 32 个分区时禁止补建，已有分区仍可单独迁移位置。支持“飞行信息”→飞行读数、“地平仪”→姿态、“舵面值”→操纵面、“起落襟翼”→机械化；每种类型只移动第一个分区。坐标按当前画布宽高换算，超出边缘时移回画布，预览列出应用后的坐标；保留尺寸、显示开关、透明度、显示器及其他分区。默认不勾选；未选择补建时，无对应分区仍跳过。重复导入不会重复创建同类型分区，取消位置迁移会同步取消补建。 另可独立勾选“迁移独立面板显示开关”：旧 `flightInfoSwitch`、`enableAxis`、`enableAttitudeIndicator`、`enablegearAndFlaps` 分别控制第一个飞行读数、操纵面、姿态、机械化分区，可作用于本次补建的分区。预览明确显示“将应用”或“未选择”；文件未指定的类型、同类型后续分区、全局 HUD 开关、布局模式和 MiniHUD 姿态开关保持不变。只有显示开关、没有坐标的文件也可导入，但需先创建对应分区。旧 MiniHUD、动力信息、引擎控制的窗口结构和背景透明度尚未迁移；画布宽高比与旧屏幕不同时，位置需要进一步手动调整。

## 模型显示分类

模型详情顶部可分别显示或隐藏重量、襟翼与起落架、舵效、失速估算、过载限制、速度与迎角限制、发动机耐热、活塞功率与曲线、喷气推力与曲线、原始字段、转动惯量、加力燃料、耐热恢复，以及无襟翼、满襟翼、机身、Fin、Stab 器件，以及升力过载估算。选择会保存到应用设置，实时和离线模型页面共用；“显示全部分类”恢复默认。旧配置默认全部显示。

分类只控制显示，不改变模型提取、实时告警或比较数据。隐藏全部分类仍保留模型来源、加载状态、实例对应及参数提取问题；被隐藏分类内的详细说明随该分类一起隐藏。隐藏曲线后重新显示会保留展开状态、已应用条件、探查位置和未应用草稿；模型参数本身保持不变，曲线会重新计算。换机或模型计算变化后重置曲线输入，该保留不跨应用重启。导入旧设置时，可勾选迁移重量、临界速度、过载、襟翼、舵效、转动惯量、加力信息和耐热恢复八类显示意图。预览说明新版分组差异，只更新文件中出现的分类；旧临界速度不会更改独立失速估算。五个旧器件分类开关也支持可选迁移；旧“千米过载”可迁移为新版升力过载估算分类；升力和阻力两个旧分类开关尚未迁移。

“襟翼与起落架”分类还显示模型襟翼限速数据点表，按开度从小到大列出百分比和 IAS 限速，保留两位小数。每次可再显示 8 点，最多查看全部 64 点；模型数据改变后回到首批。只展示有效节点，不补造档位。当前开度读数在表内插值，表外保持未知；表中数值不包含实际游戏损伤修正。

“舵效”分类显示三舵衰减速度及 `AileronPowerLoss`、`ElevatorPowerLoss`、`RudderPowerLoss` 原始系数（旧版称锁舵因数）。系数保留符号，显示三位小数，不换算成百分比，不表示实时锁舵状态，也不改变实时告警。缺失或无效时显示“—”，解析问题保留在模型提示中。

“转动惯量”分类显示 `MomentOfInertia` 的模型原值与来源路径。沿用旧版轴顺序，第 3／1／2 分量分别对应俯仰 P／滚转 R／偏航 Y；显示三位小数，不擅自推定或换算单位。缺少有效三元向量时显示未知和模型问题。旧 `showInertia` 可在导入预览中选择迁移，只改变这一分类的显示状态。

“加力燃料”分类显示整机共享容量、逐发动机消耗率和全发动机持续加力理论时限。理论时限按满燃料除以全部发动机模型消耗率之和计算，显示分钟；不代表当前剩余量或飞行剩余时间。未提供有效模型或总消耗为零时不显示时限。旧 `showNitro` 可在导入预览中选择迁移到此分类。

“耐热恢复”分类显示各发动机有效档位的 WorkTime / RecoverTime 算术平均、参与档位数和可展开的每档比值。单位为工作预算秒／恢复秒（s/s），并非实时恢复速度。缺失或零恢复时长不参与平均，零工作时长计为零；此平均分母与旧版不同。旧 `showHeatRecovery` 的显示意图可在导入预览中迁移，不改动现有热预算计算。

五类气动器件显示 CdMin、Cl0、原始临界迎角与临界升力系数，按来源路径和后掠配置分别列出。每次可再显示 8 个来源；缺失字段为“—”，不跨别名补齐或插值。迎角未扣除安装角。Fin／Stab 沿用旧字段组路由，现代别名分别是 HorStabPlane.Polar／VerStabPlane.Polar，应按完整来源辨认，而不是单凭旧名推断实际舵面。

“升力过载估算”按各后掠配置显示 350 km/h IAS、不含燃油／半油／满油下的无襟翼与满襟翼准稳态参考。缺少容量时仅显示不含燃油工况。公式为 (IAS / 对应构型和质量的 1 G 失速 IAS)²，不是结构过载限值；满襟翼工况可能超过襟翼限速。这里未单独计算 1000 米状态，也不沿用旧“千米过载”的简化数字。迁移旧 `showMaxLiftLoad` 前，预览会说明这些区别。

模型详情的“升力参数”按原始来源列出机翼面积、翼展、展弦比、后掠角和效率因数；九项面积分量不完整时显示未知，不跨后掠配置拼接。失速模型有效升力面积及按空重归一化的 m²/t 单独显示，不能当成几何面积。旧 `showLift` 可在配置导入预览中选择迁移其显示意图。

## 模型过载估算

模型面板、机型比较和过载告警共用结构载荷估算。若模型提供各后掠位置的载荷表，读数随当前后掠和燃油变化；相邻位置之间线性估算，未计外挂、损伤及改装修正。表项不完整或缺少所需后掠/燃油遥测时显示未知，不沿用上一帧阈值。

## 录制与退出

在“飞行记录”中指定“CSV 保存目录”，点击“开始记录”。尚未飞行时显示等待数据；开始收到飞行数据后写入飞行与发动机两份 CSV。点击“停止记录”结束当前记录。托盘可用时，开启录制及成功保存会发送通知；保存通知包含飞行和发动机 CSV 路径。通知是否显示由桌面控制，程序退出后不保证保留；主窗口仍显示录制状态与最近保存路径。

可在主窗口开启“通知 8111 连接状态变化（需要托盘）”。默认关闭；开启后，等待飞行、进入飞行及断线会发送状态通知，连续采样与重复连接错误不会重复提示。通知关闭或托盘不可用期间的变化不在恢复后补发。

“通知高度档及机动采样结果（需要托盘）”默认关闭。录制中每跨越新的 100 m 高度档，或滚转/过载观察达到提示条件时发送采样结果；这些观察不能视为飞机的性能极限。

“启动时自动开启记录”在下次启动生效。“下次启动进入托盘”是另一个独立选项；托盘不可用时会保留主窗口。录制过程中使用正常窗口关闭或托盘退出，让程序完成待写数据与设置保存；若界面报告退出失败，应先查看错误。主窗口隐藏时，录制启动或写入失败会恢复主窗口，便于检查错误和保存目录。

## 离线性能采样

在“记录回看”读取飞行 CSV 后，可先选择时间区间，再点击“统计爬升与机动采样”。统计过程中可点击“取消统计”，随后立即重新开始。切换图项查看高度档的到档时间、功率、推力、SEP，以及速度档的滚转率、平滑过载和机动 SEP；滑块显示具体采样值。“导出性能采样 CSV”将当前统计的全部图项保存到新文件。

统计使用原始记录，不使用时间曲线的降采样点。高度档记录上升过程中首次观察到该档时的样本；缺档不插值。到档时间从所选区间首帧起算，包含下降和数据缺失期间，不是连续爬升用时。机动筛选与平滑值不等于完整飞行包线或飞机极限。旧 CSV 可先通过已有旧格式读取入口转换，缺失字段不补零。

## 记录动态问题的遥测序列

单个 `mock_data.json` 只能回放一个时刻。需要分析飞行中反复出现的闪烁、数值跳动等问题时，可以在游戏遥测开启期间运行：

```bash
python3 script/capture_flight_sequence.py --output /tmp/voidmei-flight-capture --duration 30 --interval-ms 100
```

输出目录必须是新目录。工具只读取本机 8111 的 `/state` 和 `/indicators`，最多记录 120 秒、64 MiB；不会覆盖现有抓取。`capture.json` 记录采样时间和请求错误，按 Ctrl+C 可结束并保留已完成样本。

回放这段序列：

```bash
python3 script/mock_8111.py serve --port 8112 --snapshots-dir /tmp/voidmei-flight-capture/snapshots --scenarios-dir /tmp/voidmei-flight-capture/scenarios --scenario recording
```

将新版连接到 `http://127.0.0.1:8112`。序列不包含地图、消息或视频；两项遥测请求并非游戏内原子快照，网络错误回放为无效数据，不精确复现原网络延迟。它有助于复现数据触发的布局变化，不能单独证明图形驱动或合成器闪烁。


### 快速定位 HUD 分区设置

在“HUD 布局”中展开“调整分区位置与透明度”，点击“查找并跳转到区域”。目录按图层从底到顶排列，可搜索类型、标题、区域编号及发动机编号（例如 `ENGINE #2` 或 `战场 地图`）；空格分隔的关键词须同时匹配，不区分英文大小写。目录会标明隐藏分区，重命名、添加和移除后自动更新。

点击结果跳转至对应区域设置；每个区域标题下的“返回区域目录”可回到搜索处。搜索只筛选目录，不隐藏或卸载编辑器，因此未应用的位置／尺寸输入仍保留。展开和收起目录保留本次搜索，清除可重新显示所有区域。


### 姿态图指北针

展开“HUD 字段设置”，可启用“姿态图指北针”。红色端指北，白色端指南，指针相对当前航向旋转；俯仰／横滚和姿态参考系不改变指北方向。航向缺失时隐藏指针并提示未知，既有航向读数和独立罗盘保持不变。默认关闭。

旧 `attitudeIndicatorDisplayDirection` 开关可导入，预览会显示指北针将开启或关闭。指北针适用于纵向 HUD 与姿态分区，并随 HUD 布局恢复默认／恢复重置前布局。已有姿态分区时，即使纵向姿态图关闭，也可调整指北针、迎角极限线与参考系。


### 撤回旧设置导入

应用旧设置后，可点击“撤回上次旧设置导入”。按钮旁会显示当前可恢复与将保留的项目数量。仅恢复仍等于该次导入值的设置；导入后已改成其他值的项目保留，未涉及的设置也保留。字段列表、配色表、语音选择与整套分区布局各自作为完整设置项比较，因此后来调整过分区布局时，撤回会保留整套当前布局。

只保留本次页面最近一次有变化的导入。收起旧设置面板仍可撤回；重复导入相同值不会替换恢复点。应用失败不会覆盖恢复点，撤回失败后可重试。恢复记录不写入磁盘，重启后清除。服务器设置恢复后，当前连接仍保持原地址，点击“连接”才切换。


### 旧面板总开关格式

四类独立面板显示开关还支持旧文件中的 `:switch-key` 与 `:visible` 保存方式。识别 `flightInfoSwitch`、`enableAxis`、`enableAttitudeIndicator`、`enablegearAndFlaps`；只有 `:visible` 而没有对应总开关名时，不将它当作独立面板开关。缺省 `:visible` 按旧版规则视为关闭。

同一面板内的显式开关项优先于面板属性；不同面板间按文件顺序采用最先找到的值。导入仍在“迁移独立面板显示开关”中预览并勾选应用，不会自动改变全局 HUD。未知的面板总开关会列入未迁移报告。


### 自定义读数列数

“HUD 字段设置”和飞行／发动机分区的列数设置保留自动、单列、双列快捷选项；点击“自定义列数”可输入 1–16 并应用。分区列数可覆盖全局设置，自动模式仍按可用宽度选择单列或双列。多列采用逐行排列，适合宽区域；过窄时请减小列数或字号。

旧 `flightInfoColumn` 会在导入面板单独预览。勾选“迁移飞行信息列数”后应用到第一个飞行读数分区，包括本次补建的分区；没有对应分区时需先创建。其他分区和全局列数保持原配置。旧动力窗口的 `hudColumns` 尚未迁移。


### 分区读数字体

展开飞行或发动机区域设置中的“区域读数字体”，可分别输入标签字体和数字字体，预览后点击对应应用按钮。数字字体同时用于单位；此设置只影响该分区的表格读数，不改变界面标题、图形文字或其他分区。留空并应用后，标签继承全局文字字体，数字继承 HUD 数字字体。

字体未安装时会提示：标签回退系统默认，数字回退默认等宽字体。字体名称仍会保存，便于在安装相应字体的电脑上使用。

旧设置预览新增“迁移飞行标签字体”，优先采用“飞行信息”面板的 `:font`，未指定时兼容历史 `flightInfoFontC` 设置项。默认不勾选；应用时只修改第一个飞行读数分区，也支持本次补建的分区。字体需要在当前系统安装，数字字体、字号、位置及其他分区保持各自配置。此项可通过最近一次旧导入撤回。


### 精确调整 HUD 字号

全局 HUD 字号和每个分区的“区域文字大小”下均提供“精确字号”。展开后输入 75–200 的百分比，最多两位小数，再点击“应用字号”。例如 `137.5` 对应 137.5%。输入未通过校验时不能应用；原有滑块和分区快捷档位仍可使用。

分区显示当前生效百分比及是否继承全局。独立分区字号不随全局字号变化，尚未应用的独立分区输入也会保留；点击“继承全局”恢复继承。这里只改变文字，不调整区域位置或尺寸。字号是在系统字体缩放基础上生效的，不代表 Java 的像素字号。


### 标签、数字与单位使用不同字号

在飞行／发动机分区的“区域读数字体”中，分别填写标签、数字与单位的基础字号（6–64 sp），点击“应用三项字号”。三项一起验证和应用；“恢复默认表格字号”恢复标签 13、数字 14、单位 14 的紧凑表格基准。区域文字百分比和系统字体缩放仍在此基础上生效。此设置不改变分区尺寸、标题和其他图形。

旧“飞行信息”面板包含 `:font-size` 时，可勾选“迁移飞行表格字号”。支持偏移 -6 至 +20：数字为 24 加偏移，标签和单位为数字字号的一半四舍五入。例如 +6 导入标签 15、数字 30、单位 15，同时将第一个飞行分区的文字缩放设为 100%，避免叠加原倍率。预览明确列出这些变化；其他分区与全局设置保持原配置，也可撤回此次导入。旧边框和窗口尺寸尚未转换，导入大字号后可手动增大区域。

飞行面板的 `:font-size` 属性优先；未指定属性时，也支持该面板中嵌套分组的历史 `fontSize` 行。动力和引擎控制面板的同名行分别按各自规则可选迁移；MiniHUD 等尚未覆盖的面板仍保留未迁移报告。


### 表格字重

飞行／发动机分区的“区域读数字体”中，可分别设置标签、数字、单位为常规或粗体。标签／数字的“默认”保留现有主题字重；单位的“跟随数字”使用数值字重。点击“恢复默认表格字重”只清除字重设置，保留字体、字号、列数和其他分区。

选择迁移旧飞行表格字号时，现在会同时应用 Java 表格的字重：标签粗体、数字粗体、单位常规。导入预览会说明此变化，未勾选时保留当前字重。


### 分区边框与旧开关迁移

分区设置中的“显示区域边框”可为任意区域开启边框，并单独调整边框不透明度。背景和内容透明度保持各自配置。边框绘制在区域现有留白内，切换不会移动读数或改变区域尺寸；边框透明度设为 0 时保留开启状态但不显示。

旧设置支持 `flightInfoEdge`、`enableAxisEdge`、`enableAttitudeIndicatorEdge`、`enablegearAndFlapsEdge`。勾选“迁移独立面板边框开关”后，每类只修改第一个对应分区，也支持本次补建的分区；保留当前边框透明度与区域几何。没有对应区域时显示跳过提示。应用后可撤回。

这是旧边框开关到新版效果的转换，不是 WebLaf 阴影的像素级复刻。旧姿态、操纵面和机械化窗口为阴影额外增加的尺寸尚不自动迁移。


### 位置预览与补建选项的联动

“迁移已有分区位置”支持点击整行，坐标预览会标明“将应用”或“未选择，不修改当前位置”。未选择时仍可查看换算后的目标坐标，但不会移动现有区域。

取消位置迁移会一并取消补建。只有本次补建后才存在的分区，其字体、字号、列数和边框选项不会在取消补建后实际执行；重新勾选补建可恢复之前的样式选择并一起应用。新分区超出画布边缘时会被移回画布内。


### 按原屏幕比例迁移姿态窗口尺寸

旧文件包含 `attitudeIndicatorWidth` 或 `attitudeIndicatorHeight` 时，预览提供“迁移姿态窗口尺寸”。填写旧程序的屏幕坐标宽高（Java Toolkit 的屏幕尺寸）及原 DPI 缩放倍率，例如 1 或 1.5；未知时保持不勾选。只有尺寸输入有效且存在姿态分区时才能选择，也支持本次补建的分区。比例位置迁移不依赖这些尺寸输入，可单独使用。

换算先按 Java 规则对内容宽高乘 DPI 并取整，加上固定 4 像素留白及旧边框开启时的 20 像素外沿，再按原屏幕宽高占比转换到当前画布。旧宽高范围 100–600；只提供一个维度时，另一个采用 Java 默认宽 150／高 300。预览列出旧外框、新区域宽高和最终位置。

只改第一个姿态分区，限制宽高在画布内且不小于 80 × 40 dp，必要时将位置移回边缘。与位置迁移一起应用时，先补建、改尺寸，再按新尺寸定位。其他分区、字体、显示状态和边框设置保持原配置；边框开关可另选迁移。新版内部留白、标题和图形排布不变，因此外框比例转换不代表像素级还原旧姿态图。


### 未迁移的旧透明度属性

飞行、姿态、操纵面和机械化面板保存的 `:alpha` 会列在“未迁移”报告中。当前 Java 这四类窗口的绘制路径未读取该属性，因此不会将它直接套用到新版背景或内容透明度。可在分区设置中分别调整这两项；其他已支持设置仍可导入。只含旧透明度属性的文件可以查看原因，但没有可应用的变更。


### 搜索未迁移项目

展开“未迁移”报告后，可按名称、旧标识或来源面板／分组搜索全部记录，不受原先前 100 项的限制。搜索不区分英文大小写；空格分隔的关键词需同时匹配，可跨名称与标识匹配。报告显示匹配数量，每次加载 25 项，点击“再显示”继续查看。

相同标识在不同面板中的记录分别保留，例如飞行和姿态的 `:alpha`。收起报告再展开会保留查询与已加载数量；清除搜索或读取新的报告会重置显示。搜索仅筛选报告，不影响本次选择导入的设置。


旧飞行字号行要求 `slider` 类型和 -6 至 +20 的整数偏移。重复的飞行字号行或无效值会提示读取失败；MiniHUD、操纵面等尚未覆盖的面板同名行保留为独立未迁移记录；动力与引擎控制已分别支持自己的可选换算。字号转换仍需勾选“迁移飞行表格字号”，并沿用标签／数字／单位字号和字重的预览规则。


未迁移条目现在会显示可确定的来源路径，例如“动力信息 / 外观设置”。可输入 `动力 fontSize`，即使多个面板的项目都叫“大小”，也能定位到对应记录。来源信息只用于识别与搜索，不改变导入选择。命令行清点工具输出三列：旧标识、说明、来源路径。
